# 🔤 Web App Nomes — Frequência de Nomes no Brasil (IBGE)

Este é um aplicativo web desenvolvido em Python com [Streamlit](https://streamlit.io/) que permite consultar a frequência de nomes ao longo das décadas com base nos dados públicos do IBGE.

## 🚀 Funcionalidades

- Consulta de frequência de um nome por década
- Visualização em gráfico de barras
- Interface simples, leve e responsiva
- Conexão com a API oficial do IBGE

## Acesse
